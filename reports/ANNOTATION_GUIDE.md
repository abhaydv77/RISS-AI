# Riss-AI Annotation Guide

## Overview
Label 400 brand-creator pairs as **good**, **maybe**, or **poor** fit for a campaign collaboration.

Each pair evaluates: **Can this creator effectively execute this brand's campaign?**

---

## Label Definitions

### good
**Strong fit across most dimensions.** The creator meets mandatory requirements, aligns well with target audience, has relevant niche/content, fits budget and size preferences, and matches geography/platform needs. A brand would likely hire this creator.

**Typical signals:**
- Primary niche matches required niches
- Audience demographics (age, gender, location) align with target
- Follower count within brand's min/max range
- Platforms overlap
- Content style matches campaign tone
- No excluded traits present
- Budget can accommodate creator's rate

### maybe
**Partial fit with notable gaps.** The creator has some relevant qualities but misses on 2+ important dimensions, or has one major blocker (e.g., wrong geography, niche mismatch, budget gap). A brand *might* consider with compromises.

**Typical signals:**
- Niche is related but not exact (e.g., secondary niche matches)
- Audience partially overlaps (e.g., right age but wrong location)
- Follower count slightly outside range (near boundary)
- Platforms partially overlap
- Budget tight but negotiable
- Some excluded traits present but not deal-breakers
- Language mismatch but creator speaks required language

### poor
**Weak fit or clear mismatch.** The creator fails mandatory requirements, has fundamental audience/niche/geography mismatch, or is far outside budget/size range. A brand would not hire this creator.

**Typical signals:**
- Primary niche doesn't match required niches at all
- Audience demographics fundamentally misaligned (wrong gender, age, geography)
- Follower count far outside min/max range
- No platform overlap
- Creator has excluded traits (e.g., luxury-focused for budget brand)
- Mandatory requirements unmet (location, language, content type)
- Budget cannot cover creator's minimum rate

## Dimension Criteria

### niche_match
| Level | Criteria |
|-------|----------|
| **strong** | Creator's primary_niche ∈ brand.required_creator_niches |
| **partial** | Creator's primary_niche ∈ brand.preferred_creator_niches OR secondary_niches overlaps required/preferred |
| **weak** | No overlap between creator niches (primary + secondary) and brand required/preferred niches |

### audience_match
| Level | Criteria |
|-------|----------|
| **strong** | Age range overlaps significantly AND gender distribution matches target_gender (if not "all") AND audience_locations overlap with target_locations |
| **partial** | 2 of 3: age overlap, gender match, location overlap |
| **weak** | 0-1 of 3 match |

**Gender match rules:**
- target_gender = "female" → creator audience female% ≥ 60%
- target_gender = "male" → creator audience male% ≥ 60%
- target_gender = "all" → always matches

**Age overlap:** Parse ranges (e.g., "18-30" vs "25-34" → overlap 25-30 = partial; "18-30" vs "18-30" = strong)

**Location overlap:** Any country in common between creator.audience_locations and brand.target_locations

### geography_match
| Level | Criteria |
|-------|----------|
| **strong** | Creator's base location country ∈ brand.target_locations OR brand.mandatory_requirements explicitly requires that location |
| **partial** | Creator's audience_locations overlap target_locations but creator based elsewhere |
| **weak** | No location overlap (creator base + audience both outside target) |

### platform_match
| Level | Criteria |
|-------|----------|
| **strong** | All brand.platforms ⊆ creator.platforms |
| **partial** | At least one brand platform in creator.platforms |
| **weak** | No platform overlap |

### budget_fit
| Level | Criteria |
|-------|----------|
| **fit** | Brand budget ≥ creator rate_card minimum (parsed) |
| **uncertain** | Brand budget within 2x of creator min rate, or rate_card ambiguous |
| **mismatch** | Brand budget < creator rate_card minimum / 2 |

**Note:** Parse rate_card like "₹15,000–₹50,000" → min=15000. Convert currencies to common base (recommend INR for comparison, or USD). For annotation, use raw numbers with currency noted.

### creator_size_fit
| Level | Criteria |
|-------|----------|
| **fit** | Creator followers within [minimum_followers, maximum_followers] |
| **near** | Creator followers within 20% of boundary (e.g., 40K for min 50K, or 600K for max 500K) |
| **outside** | Far outside range |

### campaign_fit
| Level | Criteria |
|-------|----------|
| **strong** | Content types overlap strongly, content_style matches tone, no excluded_traits, mandatory_requirements met |
| **partial** | Some content overlap, style somewhat matches, minor excluded trait conflict |
| **weak** | Content mismatch, style clashes, excluded traits present, mandatory requirements unmet |

---

## Annotation Process

1. Open `annotation_pairs.json` (generated by script)
2. For each pair, read brand + creator details
3. Assign label: `good` | `maybe` | `poor`
4. Fill reasoning for each dimension
5. Write short `reason` (1-2 sentences)
6. Save completed file as `data/labels.json`

---

## Tips for Consistency

- **Mandatory requirements are hard filters**: If creator fails any mandatory_requirement → at best `maybe`, usually `poor`
- **Excluded traits are strong negative signals**: If creator clearly has excluded trait → `poor`
- **Budget is practical**: If brand budget ₹300K and creator min ₹150K → fit. If creator min ₹500K → mismatch.
- **Niche is primary**: Primary niche mismatch = weak niche_match unless secondary strongly compensates
- **Location matters for local campaigns**: Brands requiring "must be based in India" → creators outside India = weak geography_match
- **When in doubt → maybe**: Borderline cases go to maybe, not good
